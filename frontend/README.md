# Frontend

React, TypeScript e Vite. Execute npm ci e npm run dev. Configure VITE_API_BASE_URL no .env usando .env.example.

O administrador acessa Construtor visual, Plataformas, Execuções, Auditoria e Equipe. O operador solicita e acompanha os próprios cadastros.

npm run typecheck valida os projetos TypeScript. npm test executa Vitest/Testing Library. npm run build gera dist/. O teste integrado scripts/browser_smoke.py verifica a interface em navegador real usando dados descartáveis.

Consulte o README da raiz para iniciar também a API e o worker.
